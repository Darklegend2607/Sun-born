Surnborn Origin - Fabric mod for Minecraft 1.21.1
Author: Mr_mafia33

BUILD: install JDK 21, then run in this folder:
  gradle wrapper    (once, needs Gradle 8.10+ installed)
  ./gradlew build
Jar: build/libs/surnborn-1.0.0.jar  (put in mods/ with Fabric API; needed on server AND clients)

USE: /surnborn choose   (first player to run it owns the origin; /surnborn release frees it)
Keys (Options > Controls > "Surnborn Origin Keys"):
  G titan, O release projectile, V calamity fireball, X meteor,
  ] whitelist mark, [ whitelist unmark, R sun beam
